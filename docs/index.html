✈️ AI 旅遊規劃助手

運用人工智慧，快速安排專屬旅遊行程

Python Ollama Qwen2.5 Pydantic

一、專案介紹

本專案是一個 AI 旅遊規劃助手，使用者只需要輸入旅遊地點、 旅遊天數、預算及個人喜好，AI 就會自動產生旅遊計畫。

系統會安排每天的旅遊景點、推薦美食、旅遊提醒， 並提供預算方面的建議，讓使用者更方便地規劃旅程。

二、主要功能

📍 旅遊地點設定

輸入想前往的城市或國家。

📅 每日行程安排

依照旅遊天數，自動規劃每天的景點。

🍜 美食與旅遊建議

提供推薦美食及旅遊注意事項。

💰 預算建議

根據使用者輸入的預算提供規劃建議。

三、使用方法

本程式在 Windows 電腦上執行，需要先安裝 Python 專案工具 uv 及 Ollama。

1. 安裝 Ollama 模型

ollama pull qwen2.5:3b

2. 進入專案資料夾並安裝套件

uv sync

3. 執行程式

uv run python main.py

執行後輸入旅遊地點、天數、預算及喜好， AI 就會產生旅遊計畫，並儲存成 result.json。

五、AI 技術與使用說明

使用工具：

  • Python：撰寫程式及處理使用者輸入。
  • Ollama：在本機執行 AI 模型。
  • Qwen2.5:3b：負責理解需求及產生旅遊計畫。
  • Pydantic：定義資料格式並驗證 AI 輸出。

使用的 AI 功能：

本專案使用 Structured Output（結構化輸出）， 透過 Pydantic 定義資料欄位，並使用 JSON Schema 限制 AI 回傳的資料格式，讓旅遊結果更有條理， 也方便程式讀取及儲存。

AI 使用與修改說明：

開發過程中使用 AI 協助理解程式架構、撰寫程式及排除錯誤。 開發者自行建立專案環境、安裝套件、執行程式， 並確認 AI 能夠產生符合資料格式的旅遊規劃結果。

專案限制：

AI 模型在本機 Ollama 執行，因此 GitHub Pages 僅負責展示專案介紹及執行結果，無法直接在網頁上執行本機 AI 模型。
